# React（kimi-boost-react）

React + TypeScript 最佳实践:组件组合、Hooks 规范、性能与可访问性。

## 安装

**Kimi Code CLI**（TUI 内）：

```
/plugins install https://github.com/shidesheng0218/kimi-boost-react
```

或用安装器（支持 Kimi Code / Claude Code / Codex 三端）：

```bash
npx kimi-boost install react
```

安装后在 TUI 运行 `/reload` 或开新会话生效。

## 包含

- **Agent Skills**：`skills/`
- **Subagents**：`agents/`
- **Hooks**：`hooks/`
