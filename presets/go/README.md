# Go（kimi-boost-go）

Go 工程最佳实践:gofmt、错误处理、并发安全、标准库优先、测试与项目结构。

## 安装

**Kimi Code CLI**（TUI 内）：

```
/plugins install https://github.com/shidesheng0218/kimi-boost-go
```

或用安装器（支持 Kimi Code / Claude Code / Codex 三端）：

```bash
npx kimi-boost install go
```

安装后在 TUI 运行 `/reload` 或开新会话生效。

## 包含

- **Agent Skills**：`skills/`
- **Subagents**：`agents/`
- **Hooks**：`hooks/`
