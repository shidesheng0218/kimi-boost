# Vue 3 + TypeScript（kimi-boost-vue3）

Vue 3 / Vite / TypeScript 开发最佳实践:组合式 API 规范、状态管理、性能约定,外加 main 分支推送保护 hook。

## 安装

**Kimi Code CLI**（TUI 内）：

```
/plugins install https://github.com/shidesheng0218/kimi-boost-vue3
```

或用安装器（支持 Kimi Code / Claude Code / Codex 三端）：

```bash
npx kimi-boost install vue3
```

安装后在 TUI 运行 `/reload` 或开新会话生效。

## 包含

- **Agent Skills**：`skills/`
- **Subagents**：`agents/`
- **Hooks**：`hooks/`
