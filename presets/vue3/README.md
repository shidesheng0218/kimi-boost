## 安装

**Kimi Code CLI**（TUI 内，无需安装任何工具）：

```
/plugins install https://github.com/shidesheng0218/kimi-boost-vue3
```

装完运行 `/reload` 或开新会话生效。

**或用安装器**（支持 Kimi Code / Claude Code / Codex 三端，含更新、体检与卸载）：

```bash
npx kimi-boost install vue3
```
